# Source-Classification
The codes for source classification project for CASPER Labs recruitment process

Here I created the architecture and methodology of an acoustic spatial processing system designed to detect and classify multiple audio sources using a two-microphone array. The primary objective of this system is to overcome the inherent physical limitations of a 2-mic setup—specifically the symmetric "Figure-8" polar pattern ambiguity—by implementing a Recursive Minimum Variance Distortionless Response (MVDR) beamformer. 

The accuracy of the model was around 60-70%, however this can be improved further.
